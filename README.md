# whoport

Отвечает на вопрос «кто занял порт» на Windows, не заставляя связывать вывод `netstat -ano` с `tasklist`.

```
> whoport 48231
порт   протокол  адрес             pid     процесс
48231  TCP       127.0.0.1         15624   python

> whoport 48231 --kill
порт   протокол  адрес             pid     процесс
48231  TCP       127.0.0.1         15624   python
завершён python (15624)

> whoport 5000
порт 5000 свободен
```

Без аргументов показывает все слушающие порты: TCP и UDP, IPv4 и IPv6. Данные берутся напрямую из `GetExtendedTcpTable` и `GetExtendedUdpTable` в `iphlpapi.dll`, сторонних пакетов нет.

## Сборка

Нужен .NET 10 SDK.

```
dotnet build -c Release
dotnet run -- 8080
```

## Коды выхода

| Код | Значение |
| --- | --- |
| 0 | порт занят, либо процесс завершён |
| 1 | порт свободен |
| 2 | неверные аргументы |
| 3 | не удалось завершить процесс |

Так можно проверить порт в скрипте перед запуском сервера. Чтобы завершать чужие и системные процессы, нужны права администратора. Имена некоторых системных процессов без этих прав тоже могут быть недоступны.
